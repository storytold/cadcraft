Choose **Edit ▸ Interface Language** and pick a language from the list. The interface changes without a restart.

## Steps

1. Choose **Edit ▸ Interface Language**. A small window opens.
2. Open the drop-down list in it.
3. Pick one of these:
   - **Auto (system language)**
   - **English**
   - **Українська** (Ukrainian)
   - **Português (Brasil)** (Brazilian Portuguese)
   - **Deutsch** (German)
   - **Español** (Spanish)
   - **Čeština** (Czech)
   - **Русский** (Russian)
   - **Français** (French)
   - **简体中文** (Simplified Chinese)

CADCraft remembers your choice. With **Auto (system language)**, it follows your operating system's language. The same list is in **Tools ▸ Options...** on the **User Preferences** tab, under **Interface language**.

## Chinese needs a Chinese font

CADCraft does not include a Chinese font. It uses one installed on your computer: Microsoft YaHei or SimSun on Windows, PingFang on macOS, and Noto Sans CJK or WenQuanYi on Linux. If none is found, the interface stays in English and a message says to install one. The web build cannot show Chinese.

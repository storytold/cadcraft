To get going, install CADCraft, then open the sample drawing and try the command line.

1. [Install CADCraft](install.md).
2. Start the app. In the menu bar choose **Help ▸ Open Sample Drawing** to see a finished part drawing.
3. Follow [Draw your first shapes at the command line](../guides/draw-with-the-command-line.md).

If you already have DXF or DWG files, see [Open and save DXF and DWG drawings](../guides/open-and-save-drawings.md).
